# EcoHUNT-AI
Overview
Finding affordable, eco-friendly products in India can be time-consuming, causing many consumers to abandon sustainable choices. EcoDeal Voice AI, built for the "Hack For Green Bharat" initiative, bridges this gap by making green shopping as easy as speaking a sentence.

How It Works
Wrapped in a sleek, eco-green dark mode UI, EcoDeal is a 100% voice-controlled assistant. Users can simply ask for the latest deals on organic staples or energy-star appliances. Using the browser-native Web Speech API for zero-latency voice recognition and Gemini 3 Flash for lightning-fast Retrieval-Augmented Generation (RAG), the AI fetches the best discounts in real-time.

Under the Hood
The project utilizes a lightweight FastAPI backend to simulate real-time live price streaming. The architecture is intentionally designed to align with Pathway data processing patterns, ensuring it is ready to scale into a full production stream in the future. EcoDeal proves that saving the planet and saving money can go hand-in-hand.
