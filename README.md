# 🌿 EcoDeal Voice AI 

**Smart deals for a greener Bharat, just a voice command away.**

## 📖 About the Project

Finding affordable, eco-friendly products in India is often a time-consuming challenge, leading many consumers to abandon sustainable choices for cheaper, less environmentally friendly alternatives. **EcoDeal Voice AI** bridges this gap by making green shopping as easy as speaking a sentence. 

Built for the **Hack For Green Bharat** hackathon, this smart, voice-activated deal-hunting assistant empowers users to effortlessly track down the best live discounts on sustainable Indian groceries and energy-efficient electronics. It proves that saving the planet and saving money can go hand-in-hand.

## ✨ Key Features

* **100% Voice-Controlled UI:** Frictionless, hands-free deal hunting using natural speech.
* **Real-Time RAG Engine:** Lightning-fast retrieval of live prices and discounts specifically filtered for sustainable and eco-friendly goods.
* **Zero-Latency Voice Processing:** Utilizes browser-native speech recognition and synthesis—no downloads, plugins, or paid API keys required.
* **Developer-Friendly Design:** A sleek, modern Dark Mode interface with vibrant eco-green accents, perfectly aligned with the "Green Bharat" branding.
* **Pathway-Ready Architecture:** Simulated real-time streaming backend designed to easily swap into a full Pathway production environment post-hackathon.

## 🛠️ Tech Stack

* **AI & LLM:** Gemini 3 Flash (via Emergent LLM Key) for rapid Retrieval-Augmented Generation (RAG) and intelligent deal-finding.
* **Voice Interface:** Web Speech API (Browser-native STT/TTS).
* **Backend & Data Streaming:** FastAPI (simulating Pathway-style real-time data processing).
* **Dataset:** Simulated live streams (`live_prices.csv`, `live_discounts.csv`) featuring Indian eco-friendly groceries and energy-star electronics.

## 🚀 Hackathon Context: Hack For Green Bharat

This project was developed as a submission for the **Hack For Green Bharat** initiative. Our goal is to drive sustainable consumer habits across India by making eco-friendly shopping highly accessible and budget-friendly through accessible AI technology.
